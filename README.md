**Sky Courier: Pulau Karang** — game terbang 3D semu di atas kepulauan tropis fiktif. Pilot pesawat kargo kecil antar pulau: lewati cincin emas, antar kargo, dan mendarat mulus di landasan — lalu hadapi badai dengan bahan bakar yang menipis. Tiga misi berurutan, fisika terbang (throttle, pitch, bank, stall), HUD instrumen lengkap, dan suara mesin dari WebAudio.

## Run it

```sh
node serve.ts
# lalu buka http://localhost:8080 di desktop Chrome
```

Game berjalan dari berkas statis di `game/` tanpa jaringan. Tangkapan layar di `screenshots/` diambil dari adegan demo game itu sendiri (`?shot=cover|runway|rings|storm`).

## Cara main

- **W / S** — throttle naik / turun
- **Panah Atas-Bawah** — pitch (naik / turun)
- **Panah Kiri-Kanan** — belok (bank)
- **Spasi** — rem udara
- **C** — kamera kejar / kokpit · **P** — jeda · **R** — ulang misi · **M** — suara · **H** — bantuan

Jaga kecepatan di atas 55 knot agar tidak stall. Ikuti panah kuning ke cincin berikutnya; mendarat pelan di landasan (kecepatan vertikal kecil, sejajar landasan, bank hampir nol) untuk bonus pendaratan mulus.
